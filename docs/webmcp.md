# WebMCP contracts

`symbiote-ui` publishes agent-facing component metadata alongside its browser
modules. Hosts can discover component roles, actions, schemas, theme parts,
and supported WebMCP operations before mounting a surface.

Use `symbiote-ui discover` to inspect the current manifest and
`custom-elements.json` to inspect the browser registration catalog. Product
policy, permissions, persistence, and irreversible actions remain owned by the
host application.
